Learning to write proofs from a blank page

How I am changing the way I study: less recognition, more reasoning I can reconstruct.

Danny Perojevic · October 13, 2026· Updated October 15, 2026

Following a proof and writing one are different

I can read a proof, follow each line, and then get stuck when I try the problem without looking. That has been the frustrating part of Proofs & Reasoning in Math at UF. Reading more examples helps, but it does not answer the question I actually need to test: can I start the argument myself?

What I changed in my notes

My notes started as a running record of classroom board photos. I kept asking for the same additions: a proof plan, the complete argument, an explanation of the symbolic steps, and a similar problem to try alone. I need the full proof on the page so I can see what has to connect. Then I need to close it.

Give the first line a job

For a set equality, I can begin by proving one inclusion. I take an arbitrary element of the first set and unpack the definition until I can show it belongs to the second. Then I reverse the direction. That structure does not solve every detail, but it gives me something specific to do instead of staring at the statement.

The next attempt

Relations have made me slow down again, especially when several properties appear in the same question. I’m practicing naming the assumption behind each step. If I cannot explain why the next pair belongs to the relation, that is the part I need to revisit. I’m still working on doing this without a worked solution beside me.
