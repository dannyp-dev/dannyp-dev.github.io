Algorithm Studio

Try application ↗

Run Python in the browser and step backward through its execution. Source code, variables, and diagrams follow the same recorded frame.

Live project · Jun 2026

Try it yourself

Start with the ready-to-run Bubble Sort example. No sign-in or API key is needed for built-in algorithms.

  1. Click Run algorithm. The browser loads Python on the first run, which can take a moment.
  2. Step through the timeline and move backward to compare the array, variables, and active source line.
  3. Open Examples to explore BFS, Dijkstra, or A* pathfinding, or edit the code and input yourself.

AI generation and enhanced explanations are optional and require your own Gemini API key. The core visualizer works without one.

Open Algorithm Studio ↗

The question

What if stepping through an algorithm felt more like exploring a system than reading a trace?

The approach

Python executes directly in the browser through Pyodide inside a Next.js and Monaco Editor environment. Zustand captures runtime snapshots, D3.js renders reversible playback, and Gemini grounds explanations in the active execution state.

The result

The finished application removes the need for local Python setup and connects source code, execution state, visual playback, and step-specific explanations in one learning environment.

Key decisions

  • Run Python locally in the browser through Pyodide and WebAssembly.
  • Capture algorithm states with Zustand and render reversible D3.js playback.
  • Ground Gemini explanations in execution snapshots so they reflect the current step.

Technology

TypeScript / Next.js / Pyodide / Zustand / D3.js / Gemini API
